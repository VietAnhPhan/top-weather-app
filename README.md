# Weather App of The Odin Project

Weather App is an app to show your current local weather and search for specific local weather. <br/><br/>
This app demonstrate applying promise or async/await to fetch API from externals
## Installation

Use the npm to install the all dependencies
```bash
npm install
```
## Usage

```bash
npm run dev
```
